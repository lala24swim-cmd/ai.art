# ai.art — Film & AI Portfolio

Lauren Schwartz's film and AI portfolio, styled as a 2005-era video site.

`index.html` is fully self-contained (all images and scripts embedded) — no build step or other files needed.

## Publish with GitHub Pages
1. Add these files to the repo root and push to `main`.
2. On GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
3. The site goes live at `https://lala24swim-cmd.github.io/ai.art/` within a minute or two.
